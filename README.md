# بيتي 5D — مصمم المنازل والديكور ثلاثي الأبعاد (بالعربي)

تطبيق ويب كامل لتصميم المنازل على غرار Planner 5D، يعمل في المتصفح مباشرة بدون خادم وبدون تسجيل، ويدعم التثبيت كتطبيق (PWA) والعمل بدون إنترنت بعد أول زيارة.

**الرابط بعد النشر:** `https://alaasafaa88-ship-it.github.io/`

## المميزات

- **مخطط ثنائي الأبعاد (2D):** رسم الغرف بالسحب، رسم الجدران نقطة فنقطة، أبواب ونوافذ (9 أنواع)، قياس المسافات، شبكة ومقياس، أبعاد تلقائية على الجدران ومساحة كل غرفة.
- **عرض ثلاثي الأبعاد (3D):** دوران وتقريب، عرض علوي، وضع **التجوّل داخل المنزل** (W A S D أو أزرار على الجوال)، وضع ليلي يُظهر الإضاءة، أسقف اختيارية، التقاط صورة.
- **كتالوج 215 قطعة في 15 فئة:** غرفة المعيشة، المجلس العربي، غرف النوم، الأطفال، المطبخ، الطعام، الحمام، المكتب، التخزين، الإضاءة، الديكور والنباتات، الأجهزة، عناصر إنشائية (درج، أعمدة، مدفأة)، الحديقة والخارج (مسبح، أشجار، سيارة)، الرياضة والترفيه. كل قطعة لها موديل 3D مبني برمجياً، وأبعاد حقيقية، ولون قابل للتغيير، وسعر تقديري.
- **المواد:** 20 أرضية (باركيه، هيرنغبون، سيراميك، رخام، موكيت، خرسانة، حجر، عشب…) و23 لون دهان + لون مخصص لكل جدار.
- **المصمم الذكي (يعمل محلياً):**
  - تأثيث تلقائي لأي غرفة حسب نوعها (17 نوع غرفة) و10 أنماط (مودرن، كلاسيك، إسكندنافي، عربي تراثي، مينيمال، صناعي، بوهيمي، فاخر، ساحلي، مرح للأطفال) مع مراعاة مواقع الأبواب والنوافذ.
  - توليد مخطط منزل كامل من نموذج (العرض، العمق، عدد غرف النوم والحمامات وغرف الأطفال، مجلس، طعام، مكتب، حديقة) مع الأبواب والنوافذ والأثاث.
  - مساعد محادثة بالعربي: «صمّم لي فيلا 4 غرف نوم مع مجلس وحديقة بنمط فاخر»، «أثّث المطبخ»، «اقترح ألوان ساحلية»، «كم التكلفة؟»، «نصائح»، «أضف سرير مزدوج».
  - تقدير التكلفة (أثاث، أرضيات، جدران، دهان، أبواب ونوافذ) وتحليل التصميم ونصائح.
- **قوالب جاهزة:** استوديو، شقة غرفتين، شقة 3 غرف مع مجلس، فيلا، منزل عائلي، مكتب، مشروع فارغ.
- **المشاريع:** حفظ محلي مع صور مصغرة، حفظ تلقائي، تراجع/إعادة، استيراد/تصدير JSON، تصدير صورة المخطط والعرض 3D، قائمة الأثاث CSV، طباعة/PDF، رابط مشاركة يحتوي المشروع كاملاً.
- **واجهة عربية RTL بالكامل** ومتجاوبة مع الجوال (شريط سفلي، لوحات منزلقة، تكبير بإصبعين).

## التشغيل محلياً

لا يحتاج إلى بناء. افتح `index.html` عبر أي خادم ثابت:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## بنية المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق والنوافذ المنبثقة |
| `css/style.css` | التنسيق (RTL + جوال) |
| `js/catalog.js` | الكتالوج و بُناة الموديلات ثلاثية الأبعاد |
| `js/materials.js` | أنسجة الأرضيات المولّدة برمجياً وألوان الدهان |
| `js/state.js` | نموذج المشروع (غرف، جدران، فتحات، عناصر)، تراجع/إعادة، التخزين |
| `js/editor2d.js` | محرر المخطط على Canvas (أدوات، سحب، تدوير، رموز القطع) |
| `js/view3d.js` | العرض ثلاثي الأبعاد بـ Three.js (جدران بفتحات، أبواب، نوافذ، إضاءة، تجوّل) |
| `js/ai.js` | المصمم الذكي: تأثيث، توليد مخططات، أنماط، تكلفة، نصائح، محادثة |
| `js/templates.js` | القوالب الجاهزة |
| `js/app.js` | ربط الواجهة بالمنطق |
| `vendor/` | Three.js r128 و OrbitControls (رخصة MIT) |
| `manifest.json`, `sw.js` | تطبيق ويب تقدّمي يعمل بدون إنترنت |

## ملاحظات

- جميع البيانات تُحفظ في متصفحك فقط (localStorage).
- الأسعار تقديرية لأغراض التخطيط، ويمكن تغيير رمز العملة من الإعدادات.
- المصمم الذكي يعمل بقواعد محلية ولا يرسل أي بيانات إلى الإنترنت.
