# Recon: لعبة "هدّاف" (على نمط Score! Hero من First Touch Games)

المصدر: صفحة متجر Google Play (لقطة شاشة من المستخدم: 4.5 نجمة، +100 مليون تنزيل،
إعلانات وشراء داخل التطبيق) + المعرفة العامة بفئة ألعاب "ارسم مسار الكرة". لم يُقرأ أي
كود أو واجهة برمجية خاصة باللعبة الأصلية، ولم تُستخدم أي صورة أو صوت منها.

## النطاق
- المنصة: ويب (PWA) من GitHub Pages، يُثبَّت على الهاتف ويعمل بدون إنترنت. لا خادم.
- الشريحة: الحلقة الأساسية = اختيار مستوى → مشهد تسديد → رسم مسار بالإصبع →
  هدف/إخفاق → نجوم ونقود → المستوى التالي. زائد القلوب (الطاقة)، إعادة اللقطة،
  تخصيص البطل، البطولات والكؤوس والإحصاءات.
- الجمهور: لاعبو الهاتف العرب الذين يريدون لعبة كرة سريعة بلا تنزيل من المتجر.

## التدفقات
- F01 لعب مستوى: S01 → S03 → رسم → هدف → S04 → S03 (التالي). 3 نقرات + رسمة.
- F02 إخفاق وإعادة: S03 → S05 → إعادة (قلب) أو إعادة اللقطة (نقود) → S03.
  حافة: لا قلوب → S06؛ لا نقود → زر الإعادة بالنقود معطّل.
- F03 إنهاء بطولة: آخر مستوى في الموسم → كأس في S02 و S09.
- F04 تخصيص البطل: S01 → S08 → يظهر في الملعب و S04 فوراً.

## المكوّنات
زر رئيسي/شبح/خطر، زر أيقونة، شارة قلوب (مع عدّاد)، شارة نقود، بلاطة مستوى
(4 حالات)، صفحة سفلية (modal)، لافتة في الملعب (هدف/إخفاق)، مقياس قوة،
تلميح، إشعار toast، لوحة نتيجة المباراة، لاعب (بطل/زميل/مدافع/حارس)، كرة بظل.

  evidence: S01 و S04 و S08 و S09. ثقة عالية.

  evidence: S03 و S02. ثقة متوسطة (المشاهد الأصلية مكتوبة يدوياً؛ هنا مولّدة).
- Attempt: touches, speed, curve, loft, result(goal|save|block|post|over|wide|out|stop)
